# 🍳 AI Recipe Generator

A beautiful modern iOS recipe app built using **SwiftUI** that generates recipes offline using smart ingredient matching — no API required.

---

## ✨ Features

- 🧠 Smart ingredient matching
- 📱 Modern SwiftUI UI
- 💾 Fully offline
- ❤️ Favorites system
- 🎲 Surprise Me feature
- 🔥 Nutrition information
- ⏱ Cooking time & difficulty
- 📤 Share recipes
- 🌈 Beautiful pastel UI
- ⚡ Smooth animations
- 🌙 Light modern theme

## 🚀 How It Works

1. Enter ingredients
2. App searches local recipe database
3. Best matching recipe is generated
4. Recipe details are displayed beautifully

No internet or API needed.

## 📦 Installation

1. Clone the repository

```bash
git clone https://github.com/charveemasand108/Recipe-IOS--App.git
```

2. Open in Xcode

```bash
open AIRecipeGenerator.xcodeproj
```

3. Run on simulator or device

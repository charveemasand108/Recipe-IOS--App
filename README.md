# 🚀 How It Works

1. Enter ingredients
2. App searches local recipe database
3. Best matching recipe is generated
4. Recipe details are displayed beautifully

No internet or API needed.

# 📦 Installation

## Clone the repository

```bash
git clone https://github.com/charveemasand108/Recipe-IOS--App.git
```

## Open in Xcode

```bash
open "AI Recipe Generator.xcodeproj"
```

## Run the App

Run on iOS Simulator or a physical device.
